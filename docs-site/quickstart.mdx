# Quickstart Guide

Kova is an autonomous software-use and product-flow continuous validation platform. It automatically discovers your web app's interactive paths, builds a living Product Graph, and continuously validates user flows in CI/CD without brittle scripts.

## 1. Create your Account & Project

1. Sign up at [https://app.kova.dev](https://app.kova.dev).
2. Complete the initial 4-step setup wizard:
   - Provide your application's base URL (e.g. `https://staging.acme.com`).
   - Add test user credentials for authenticated routes.
   - Run autonomous discovery to crawl routes and generate your Product Graph.
   - Run your baseline continuous validation run.

## 2. Generate a Scoped API Token

1. Navigate to **Settings > API Tokens**.
2. Click **Generate New Token**.
3. Select the `ci:validate` scope.
4. Copy your token (starts with `kova_tok_...`).

## 3. Add to GitHub Actions

Add `KOVA_API_TOKEN` to your repository's GitHub Secrets, then add this step to `.github/workflows/ci.yml`:

```yaml
- name: Run Kova Continuous Validation
  uses: kova-ai/action-validate@v1
  with:
    api-token: ${{ secrets.KOVA_API_TOKEN }}
    project-id: ${{ vars.KOVA_PROJECT_ID }}
    base-url: ${{ steps.deploy-preview.outputs.url }}
```
