# Core Concepts

Kova replaces fragile end-to-end testing scripts with an autonomous cognitive model of your product.

## 1. Product Graph
The Product Graph is a semantic, directed graph of your web application's screens, components, actionable elements, and state transitions.
- **Nodes**: Pages, modals, interactive cards, and view states.
- **Edges**: Transitions triggered by user actions (clicks, form submits, OAuth redirects).

## 2. Product Flows
Flows are executable user journeys across your Product Graph (such as Signup, Onboarding, Checkout, Team Invite). Each flow contains:
- **Prerequisites**: Required user auth state or database fixtures.
- **Actions**: Sequence of intent-driven interactions.
- **Invariants**: Semantic assertions that must remain true (e.g. "Total price matches sum of cart items", "No unhandled 500 errors").

## 3. Autonomous Self-Healing
When frontend code changes (e.g. CSS refactors, DOM restructuring, changed button selectors), Kova uses visual heuristics, intent matching, and accessibility trees to self-heal flow selectors without breaking your CI pipeline.
