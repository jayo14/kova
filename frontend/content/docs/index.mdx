# Welcome to Kova

Kova is an **autonomous software-use and product-flow execution platform**. Give Kova a URL, credentials, and a goal; it opens an isolated Playwright browser, explores the application, discovers workflows, executes product journeys, and records step-by-step evidence.

It is not a script recorder. It acts like a real user: navigates real UIs, handles logins, runs journeys, and captures screenshots, audit logs, and network requests so you can verify product behavior without writing brittle scripts.

## What Kova proves with evidence

Every run produces evidence, not just a pass/fail flag:

- Step timeline with actions and outcomes
- Screenshots and viewport frames from the isolated browser
- Network request log
- Deterministic verification verdict (success is proven by checks, not by "an action was attempted")

See [Results and evidence](guides/results-and-evidence).

## Core principles

- **Isolated browser execution**: each run uses a dedicated Chromium context inside a Celery worker. The FastAPI process never launches browsers.
- **AI proposes, code disposes**: model output is validated into typed schemas before any browser action. Only deterministic verification can mark a run complete.
- **Evidence-backed verification**: success requires proof; VLM checks are advisory only.

See [How Kova works](how-it-works) for the architecture behind these claims.
