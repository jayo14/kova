# Brag Plan: Kova

## What is this app?
Kova is an autonomous product-flow testing agent that takes any web application URL and a goal, explores the interface like a real human user, bypasses modals and auth barriers, and validates critical user journeys with cryptographic screenshot evidence.

## The angle
"AI built your app fast. But does it actually work?" Kova replaces fragile Selenium/Playwright scripts and manual walkthroughs with an autonomous agent that navigates real UIs, handles unexpected popups and cold starts, and deterministically proves every step: "AI Proposes. Code Disposes."

## Hook (first 2-3 seconds)
A bold, editorial opening statement: "Let an agent use your software." A live URL pill snaps onto the screen with a typing cursor entering `https://yourproduct.com` and a sharp click on `Explore →`.

## Key moments (the middle)
- The live browser viewport: An autonomous mouse cursor glides into a fintech app, selects "Send transfer", and executes multi-step inputs.
- Obstruction resilience: An annoying "Install App" modal blocks the screen — Kova detects it, dismisses it, and keeps exploring unhindered.
- Verification payoff: Floating glass cards pop with green checks (`Report Verified`, `Screenshot Evidence`), showing cryptographic hash proof instead of vague assertions.

## Outro / punchline
"AI Proposes. Code Disposes." The iconic Kova brand lockup with terracotta sand aesthetics (`#8A3513`, `#D58A56`, `#FBF7F0`) and the final call to action: `Explore your app at kova.dev`.

## User flow worth showing
Entry: Enter target URL (`https://yourproduct.com`) into the pill.
Key action: Agent navigates routes, dismisses modal obstructions, and interacts with real controls.
Result: Verified cryptographic report with screenshot hashes and green confirmation badges.

## Storyboard

### Scene 1 — The Hook & Target Entry — 3.5s
A warm sand canvas with floating ambient orbs. The bold headline appears in Bricolage Grotesque: "Let an agent *use* your software." An interactive URL pill slides in. The text `https://yourproduct.com` types out with rapid keystrokes, and the cursor clicks `Explore →`.
Sequential/interaction: Yes — headline settles, URL types, button clicks with active scale pulse.
Audio intent: Upbeat curiosity with immediate momentum.
Audio-coupled idea: Keypress typing clicks followed by a crisp button tap.
Transition mood: Fast snap → Scene 2

### Scene 2 — Autonomous Exploration — 5.0s
A sleek browser mockup card glides into the center against a warm terracotta dot grid. Inside the browser, an autonomous cursor glides toward a real UI ("Send transfer"). An install-app modal pops up to obstruct — Kova instantly identifies it, clicks "Got it", and seamlessly resumes interacting with the controls.
Sequential/interaction: Yes — browser appears, modal interrupts, modal dismissed, cursor resumes clicking.
Audio intent: Confident competence and technical delight.
Audio-coupled idea: Cursor movement whoosh, modal popup tick, dismiss click.
Transition mood: Smooth push → Scene 3

### Scene 3 — Cryptographic Evidence & Verification — 4.5s
The browser transitions into proof mode. Floating glass cards animate into view: a "Report" card with animated green checkmarks, and a 4-tile "Screenshot Evidence" grid showing cryptographic hash verification stamps. A bold banner states: "No flaky scripts. Cryptographic evidence."
Sequential/interaction: Yes — green checks light up sequentially, screenshot tiles cascade in with subtle tilt.
Audio intent: Rewarding verification and reliability.
Audio-coupled idea: Sequential soft chimes for green checks, tile snap sounds.
Transition mood: Cinematic zoom-out → Scene 4

### Scene 4 — Punchline & Outro — 5.0s
The screen resolves to the deep rust and cream brand lockup. The headline delivers the core philosophy: "AI Proposes. Code Disposes." Below it, the primary brand mark: "Kova." with an orange accent dot, followed by the pill badge: "Autonomous Product-Flow Testing" and the URL: "kova.dev".
Sequential/interaction: Yes — philosophy punches in, logo stamp scales into place, subtle ambient particles breathe.
Audio intent: Authoritative, memorable, final resolution.
Audio-coupled idea: Warm bass swell and gentle music fade-out.
